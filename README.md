# 🐰🎀 Bunny Pink Cafe

A cute little web app where you click the bunny chef to discover a random dessert.
Built as a mini portfolio project with plain **HTML, CSS and vanilla JavaScript**, no frameworks.

## ✨ Features

- Click the bunny (or press Enter / Space) to get a random dessert
- Never shows the same dessert twice in a row
- Cute pink pastel theme with floating decorations and smooth animations
- Responsive layout for phone, tablet and desktop
- Accessible: keyboard focus styles, ARIA labels, `prefers-reduced-motion` support

## 🛠️ Tech Stack

| Part | Tech |
| --- | --- |
| Structure | HTML5 |
| Styling | CSS3 (custom properties, grid, keyframe animations) |
| Logic | Vanilla JavaScript (ES6) |
| Fonts | Fredoka & Poppins (Google Fonts) |

## 🚀 Run Locally

Just open `index.html` in your browser, or serve the folder:

```bash
npx serve .
```
